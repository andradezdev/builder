O **Builder** é uma ferramenta *low-code* de construção visual de páginas web, landing pages e portais corporativos integrada de forma nativa ao ecossistema **ERPZ** e seu **Framework**.

Com uma interface moderna, ágil e inspirada nos melhores editores de design (como o Figma), o aplicativo permite criar layouts responsivos de alta performance, conectar elementos visuais a dados dinâmicos do banco de dados e publicar páginas com um único clique.

---

## 🚀 Principais Recursos

- **Editor Visual Moderno:** Arraste, solte e estilize elementos em tela com controle absoluto de espaçamento, tipografia, cores e alinhamento flexível (*Flexbox* e *Grid*).
- **Publicação em 1 Clique:** Publique páginas diretamente no portal corporativo com roteamento automático, sem necessidade de deploy complexo ou recarga de servidor.
- **Design 100% Responsivo:** Alterne instantaneamente entre visualizações de Desktop, Tablet e Mobile, configurando estilos específicos para cada dispositivo.
- **Conexão Nativa com Dados do ERPZ:** Ligue qualquer componente ou bloco a tabelas e campos do sistema (ex: produtos, artigos de blog, formulários de contato, dados cadastrais).
- **Performance e SEO Otimizados:**
  - Código limpo, sem scripts desnecessários ou excesso de dependências, garantindo pontuações máximas no *Google Lighthouse*.
  - Configuração granular de tags de SEO, prévia de visualização no Google (*Google Snippet Preview*) e imagens Open Graph.
- **Geração e Auxílio por IA:** Crie rascunhos de páginas e seções completas a partir de prompts descritivos de texto.
- **Suporte Nativo a Modo Escuro (*Dark Mode*):** Alternância automática conforme a preferência do sistema operacional do visitante ou controle manual na página.
- **Scripts e Estilos Avançados:** Liberdade para desenvolvedores adicionarem código CSS customizado, bibliotecas externas e scripts de interação do lado do cliente.
- **Métricas e Analítica Integradas:** Acompanhamento de visualizações de página, visitantes únicos e principais fontes de tráfego.
